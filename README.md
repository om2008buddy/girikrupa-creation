# ગુરુકૃપા ક્રિએશન (Gurukrupa Creation)
### કુર્તી-પેન્ટ મેન્યુફેક્ચરિંગ નફા હિસાબ & જોબવર્ક મેનેજમેન્ટ સિસ્ટમ

---

## 🚀 ઝડપી શરૂઆત (Quick Start)

### 1. એપ્લિકેશન શરૂ કરવા માટે:
ટર્મિનલમાં નીચેનો કમાન્ડ રન કરો:
```bash
./start.sh
```
અથવા:
```bash
~/.local/bin/node server.js
```

### 2. એપ્લિકેશન લિંક્સ (URL):
- **કમ્પ્યુટર / લેપટોપ (Web App):** [http://localhost:4500](http://localhost:4500)
- **એન્ડ્રોઇડ મોબાઇલ (Android App):** [http://192.168.1.2:4500](http://192.168.1.2:4500)
  *(મોબાઇલ તમારા વાઇફાઇ સાથે કનેક્ટ હોવો જોઈએ)*

### 3. સુરક્ષા પાસવર્ડ (Security Passcode):
```
6390
```
> માત્ર આ પાસવર્ડ દાખલ કરવાથી જ એપ્લિકેશન ખૂલશે.

---

## 📱 એન્ડ્રોઇડ મોબાઇલમાં એપ ઇન્સ્ટોલ કરવાની રીત (Android PWA):
1. તમારા મોબાઇલના **Chrome બ્રાઉઝર**માં જાઓ અને લિંક ખોલો: `http://192.168.1.2:4500`
2. પાસવર્ડ `6390` દાખલ કરો.
3. ક્રોમમાં જમણી બાજુ 3 ટપકાં (Menu) પર ક્લિક કરો અને **"Add to Home screen"** અથવા **"Install app"** પસંદ કરો.
4. તમારા મોબાઇલની હોમ સ્ક્રીન પર **"ગુરુકૃપા ક્રિએશન"** નો ઓફિશિયલ GK લોગો ધરાવતી એપ આવી જશે!
5. **ખાસિયત:** મોબાઇલ અને કમ્પ્યુટર બંને **એક જ ડેટાબેઝ (`gurukrupa.db`)** શેર કરે છે. મોબાઇલમાં કરેલી એન્ટ્રી તરત જ કમ્પ્યુટરમાં દેખાશે અને કમ્પ્યુટરમાં કરેલી એન્ટ્રી મોબાઇલમાં દેખાશે.

## ✨ મુખ્ય મોડ્યુલ્સ & સુવિધાઓ (All 9 Modules Included)

1. **વેપારી પાસેથી આવેલ માલ (Inward Goods):**
   - વેપારી નામ, ડિઝાઇન, કુલ પીસ, વેપારી પાસેથી નક્કી કરેલ ભાવ (Rate), અને ઓર્ડરની કુલ રકમ.
   - માલની સ્થિતિ: *કામ ચાલુ છે / પ્રેસમાં છે / તૈયાર છે / વેપારીને જમા*.

2. **કારીગર ભાવ & કામ એન્ટ્રી:**
   - દરેક કારીગર મુજબ તારીખવાર કામની એન્ટ્રી.

3. **કારીગર ઉપાડ અને કુર્તી-પેન્ટ અલગ અલગ ભાવ:**
   - કુર્તી સિલાઈ પીસ × ભાવ
   - પેન્ટ સિલાઈ પીસ × ભાવ
   - અન્ય કામ / ઓલ્ટરેશન પીસ × ભાવ
   - **કારીગર ઉપાડ (Advance Cash):** રોકડ / Google Pay / બેંક મોડ સાથે.
   - **કારીગર ખાતાવહી & સ્ટેટમેન્ટ:** કુલ કામ, કુલ ઉપાડ અને બાકી ચૂકવવાની રકમ.
   - **કારીગર પગાર રસીદ પ્રિન્ટ:** સત્તાવાર લોગો અને સહીઓ સાથેની પગાર રસીદનું 1-ક્લિક પ્રિન્ટિંગ.

4. **ડિઝાઇન કેટલોગ (Design Master):**
   - ડિઝાઇન નંબર, ડિઝાઇન નામ, વેપારી ભાવ (Party Rate), કારીગર કુર્તી ભાવ, કારીગર પેન્ટ ભાવ, પ્રેસ ભાવ અને અંદાજિત મટીરીયલ ખર્ચ.
   - પ્રતિ પીસ ચોખ્ખો અંદાજિત નફો લાઈવ ગણતરી થાય છે.

5. **પ્રેસ હિસાબ (Ironing & Pressing):**
   - પ્રેસ વાળાનું નામ, ડિઝાઇન, પ્રેસ થયેલા પીસ, પ્રેસ ભાવ અને કુલ બિલ રકમ.
   - ચુકવણી સ્થિતિ (બાકી / ચૂકવેલ).

6. **મટીરીયલ્સ / કાચો માલ ખર્ચ:**
   - કાપડ, દોરો, બટન, ઝિપ, ઇલાસ્ટિક, લેસ, પેકિંગ બેગ, હેંગર વગેરેનો જથ્થો, એકમ, ભાવ અને કુલ રકમ.

7. **કારખાના ખાતા ખર્ચ (Factory Overheads):**
   - લાઈટ બિલ (Electricity)
   - કચરો વાળવા વાળો (Cleaning)
   - કારખાના ભાડું (Factory Rent)
   - પાણી બિલ / કેન (Water)
   - ચા-નાસ્તો (Tea & Refreshments)
   - મશીન રિપેરિંગ / ઓઈલ / સોય
   - સ્ટેશનરી & પરચૂરણ ખર્ચ

8. **આવક-જાવક હિસાબ & ચોખ્ખો નફો (P&L Net Profit Engine):**
   - કુલ વેપારી આવક
   - (-) કારીગર સિલાઈ ખર્ચ
   - (-) પ્રેસ ખર્ચ
   - (-) મટીરીયલ્સ ખર્ચ
   - (-) કારખાના ખાતા ખર્ચ
   - (-) ફિક્સ સ્ટાફ પગાર
   - **(=) ચોખ્ખો નફો (Net Profit ₹)** અને નફા ટકાવારી (%)
   - ફિલ્ટર: આજે, આ અઠવાડિયે, આ મહિને, અથવા બધો સમય.

9. **ફિક્સ પગાર સ્ટાફ (Fixed Staff):**
   - કટિંગ માસ્ટર, પેકિંગ, હેલ્પર વગેરે.
   - દૈનિક હાજરી, કામના કલાકો (Hours Worked), ઓવરટાઈમ/અડધો દિવસ અને કલાક મુજબ ગણેલો પગાર.

10. **વેપારી માલ ડિલિવરી ચલણ (Challan with Auto Print):**
    - વેપારીને તૈયાર માલ જમા કરાવતી વખતે ચલણ બની જાય છે અને ઓટોમેટિક પ્રિન્ટ નીકળી જાય છે.
    - કંપની લોગો (GK Emblem), વેપારી વિગત, ડિઝાઇન વિગત, નંગ, ભાવ, સરવાળો અને બંને પક્ષની સહીઓ.

## 🔒 ડેટાબેઝ & બેકઅપ
- ડેટાબેઝ: `gurukrupa.db` (SQLite)

- સેટિંગ્સ પેજમાંથી 1-ક્લિકમાં સંપૂર્ણ ડેટાબેઝ બેકઅપ (JSON) ડાઉનલોડ કરી શકાય છે.
